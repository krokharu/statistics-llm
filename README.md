# GI-Gemma

Public research-design repository for evidence-grounded conversation analysis.

This initial README establishes the repository. The reviewed design, candidate source, and invented synthetic tests will be developed on the dedicated `gi-gemma/design-v0` branch. No model loading, inference, or training result is claimed here.

Do not publish real transcripts, participant information, private source links, credentials, model weights, or private work logs in this repository.
